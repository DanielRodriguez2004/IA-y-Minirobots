
# Diagramas de Voronoi – Ipiales

Este proyecto genera diagramas de Voronoi para analizar la distribución espacial de:

- Centros de atención de salud
- Droguerías
- Colegios

en la ciudad de Ipiales, Nariño.

# Requisitos
Se necesita tener en la misma carpeta del archivo de codigo punto4.py las imagenes correspondientes a analizar (colegios.png, drogueria.png, hospital.png)
