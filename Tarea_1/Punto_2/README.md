Primeramente, descargue el archivo **"Automata_Probabilistico_Enfermedad_Colab.ipynb"**.

Después, entre a [Google Colab](https://colab.research.google.com/) y seleccione la opción **Subir Notebook**, donde debe seleccionar el archivo que acaba de descargar.

Una vez abierto el Notebook, podrá revisar paso a paso cómo se implementó la simulación de un **Autómata Celular Probabilístico** para modelar la difusión de una enfermedad en un espacio bidimensional. En las últimas secciones podrá observar los resultados obtenidos, incluyendo la evolución de los diferentes estados de la población, la configuración final del retículo y la animación de la simulación.

También es posible ejecutar el código localmente utilizando **Python** y **Visual Studio Code**. Para ello, es necesario tener instaladas las librerías `numpy` y `matplotlib`.

Para instalar las librerías, ejecute en la terminal:

```bash
pip install numpy matplotlib
```

Posteriormente, para ejecutar el programa localmente, abra la carpeta del proyecto en Visual Studio Code y ejecute el archivo **"automata_probabilistico_enfermedad.py"**.

**Nota:** La primera vez que se ejecute la animación, puede tardar algunos segundos en comenzar a mostrarse.
